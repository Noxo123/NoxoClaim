# Security Policy

## Supported versions

Security fixes are applied to the current `main` line and the latest published release.

## Reporting a vulnerability

Please do not open a public GitHub issue for an undisclosed vulnerability.

When reporting a security problem, include:

- affected NoxoClaim version;
- Paper version;
- Java version;
- reproduction steps or a minimal proof of concept;
- expected and actual behaviour;
- relevant logs or stack traces with secrets removed.

Please remove server addresses, player data, tokens, API keys and other private information from the report.

## Scope

Security reports are especially useful for:

- claim protection bypasses;
- permission bypasses;
- unsafe command handling;
- data loss or corrupted persistence;
- updater/download integrity issues;
- denial-of-service conditions;
- unsafe third-party integrations.

Reports about ordinary bugs should use GitHub Issues instead.
